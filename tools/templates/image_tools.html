How to choose an image workflow

Generate from an idea

Use a text-to-image tool when no source image exists yet and the goal is concept art, illustration, a mockup or a new visual direction.

Edit an existing image

Choose an editor or product-photo workflow when the image already exists and needs cleanup, layout, background work or commercial presentation.

Fix one technical problem

A focused background remover or upscaler is often faster when you only need one specific transformation.
